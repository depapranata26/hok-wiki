# Wiki Honor of Kings (Pribadi)

Wiki pribadi Depa tentang Honor of Kings. Tujuannya: jadi **bahan sumber AI** — kalau Depa
tanya soal HoK, AI baca wiki ini dulu sebelum jawab, supaya jawabannya nyambung sama data
yang udah dikurasi di sini, bukan ngarang dari ingatan.

## Cara pakai

- Semua konten berupa file **Markdown** di repo ini. AI membaca file-file ini langsung.
- **GitBook (opsional, buat tampilan enak dibaca):** sambungkan repo ini lewat Git Sync
  GitBook, jadi wiki bisa dibaca lewat web GitBook sekaligus tetap tersimpan sebagai
  Markdown di sini. GitBook bukan tempat penyimpanan utama — repo ini yang utama.
- **Aturan isi:** fakta (angka, nama skill, efek) harus dari sumber resmi atau situs data
  terverifikasi, dan dicatat sumbernya di bawah tiap halaman. Opini/strategi ditandai
  jelas sebagai opini. Jangan tulis angka dari ingatan tanpa cek.

## Struktur

- `heroes/` — satu file per hero (skill, build, counter, tips).
- `items.md` — daftar item: stat, efek, harga, cocok untuk siapa.
- `arcana.md` — daftar arcana: efek per level, set yang umum dipakai.
- `meta.md` — peran/role, lane, rotasi, komposisi tim, counter pick, meta patch berjalan.
- `patch-notes.md` — ringkasan patch yang berpengaruh ke meta.
- `SUMMARY.md` — daftar isi / navigasi.
